# CloudRadio 乡音计划

基于 Flutter 的云端电台 App（课程设计项目）。

## 功能特性

- 📻 HLS / HTTP 实时直播流播放（media_kit）
- 🔔 后台播放与系统通知栏播控（audio_service）
- ⭐ 收藏（shared_preferences）
- 🖥️ 适配桌面端与移动端

## 技术栈

Flutter 3.x / Dart

## 本地运行

```bash
git clone https://github.com/qyc09/cloud_radio_app.git
cd cloud_radio_app
flutter pub get
flutter run
